# 桥译 · 正式版

下载 **BridgeTranslate.zip**，解压后在 Chrome / Edge 扩展管理中加载 `extension` 文件夹。`SHA256SUMS.txt` 提供安装包校验值。

支持可选回车译后发送（默认关闭）、逐段双语、中文模式、原生代码复制、中文表格与 Markdown 全文复制，以及侧栏可见会话标题翻译。自带 URL、Key 与模型，提供四类协议适配。

无痕模式：普通窗口安装与配置 → 扩展详情允许无痕 / InPrivate → 新建无痕窗口登录 Claude 并刷新。详细步骤见 `docs/使用指南.md`。

当前仅维护浏览器扩展。真实 Claude 网页和实际 API 仍需安装验收，详见 `docs/验证记录.md`。
