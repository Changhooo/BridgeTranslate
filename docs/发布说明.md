# 桥译 · 正式版

- **BridgeTranslate.zip**：完整源码与浏览器扩展。解压后在 Chrome / Edge 扩展管理中加载 `extension` 文件夹。
- **BridgeTranslateWindows.zip**：不依赖 Mods 的 Windows x64 独立版。完整解压后运行 `BridgeTranslate.exe`，需要系统 WebView2 Runtime。
- **bridge-translate-demo.mp4**：45 秒截图宣传片，展示浏览器功能，操作衔接为动画示意。
- **SHA256SUMS.txt**：安装包与视频的 SHA256 校验值。

浏览器版支持可选回车译后发送（默认关闭）、逐段双语、中文模式、代码与 Markdown 复制，以及侧栏可见会话标题翻译。自带 URL、Key 与模型，提供四类协议适配。

无痕模式：普通窗口安装与配置 → 扩展详情允许无痕 / InPrivate → 新建无痕窗口登录 Claude 并刷新。详细步骤见 `docs/使用指南.md`。

Windows 独立版在自己的窗口写中文，绑定 Claude 窗口填入英文；从用户选择的本地记录或可访问文字区域读取回答。它不接管 Claude 原输入框回车，不修改 Claude 配置。侧栏标题翻译仅适用于浏览器扩展。

自动检查与编译不等于真实客户端验收。Windows Claude 的控件、焦点、剪贴板、输入法与真实 API 仍需本机验收，程序未签名，详见 `windows/验证记录.md`。网页中文显示不能保证账号不受平台限制。
