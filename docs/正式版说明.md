# 桥译正式版说明

本次将最后一版功能作为正式版交付，仓库名为 `Changhooo/BridgeTranslate`，界面名称为「桥译」，安装包使用固定文件名 `BridgeTranslate.zip`。不保留旧版编号目录或旧版发布记录。

浏览器要求 manifest 必须带数字版本号，故 `manifest.json` 与 `package.json` 保留内部版本 `1.0.0`，用于扩展识别和后续升级；这不会出现在产品名称或安装包名称中。

## 当前功能

- 用户自带 URL、模型名称和 Key，四类常见模型协议。
- 网页中文提问一键转英文；手动翻译按钮只翻译不发送。
- 可选「回车译后发送」，默认关闭，保存本机偏好。
- 回答生成中逐段翻译，中文紧跟英文，最多两个请求并发。
- 原文／双语／中文切换，继承原字号与 Markdown 结构。
- 只翻译文字，保留代码、公式、图片和图表。
- 原生代码复制、中文表格及 Markdown 全文复制。
- 可见会话标题本地翻译，悬停看原文，关闭恢复，不修改云端名称。
- 取消、手动重试、改稿保护与会话切换保护。
