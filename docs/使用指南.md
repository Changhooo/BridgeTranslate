# 桥译使用指南

桥译在 Claude 网页中完成中文提问转英文，以及英文回答逐段转中文。翻译使用你填写的模型接口，不需要部署服务器或编译代码。桌面 Chrome 116+ 是主要目标；Edge 使用同类扩展 API，尚未完成实机验证。手机与 Firefox 暂不支持。

## 准备材料

- 安装有 Chrome 的电脑，或自行验收兼容性的 Edge。
- 可以正常使用的 Claude 网页账号与网络环境。
- 翻译服务商的 **API URL、model ID、API Key**。网页聊天订阅通常不等同于 API 额度，请以服务商说明为准。
- 下载当前仓库的代码：GitHub 仓库首页 → **Code → Download ZIP**；也可使用单独的 `BridgeTranslate.zip` 安装包。

文档中的 `api.example.com`、示意模型名和占位密钥仅用于说明，不能直接连接服务。请不要将真实 Key 写入代码、截图、视频或 GitHub。

## 首次安装

1. 将 ZIP 解压到固定目录，例如 `Documents/bridge-translate`。后续不要删除或移动这个目录。
2. 在**普通窗口**的地址栏打开 `chrome://extensions`。Edge 打开 `edge://extensions`。
3. 开启页面的「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择 **extension 文件夹**，即能直接看到 `manifest.json` 的那一层。不要选择 ZIP 文件或仓库最外层。
6. 确认扩展列表中出现「桥译 · Bridge Translate」，并处于启用状态。
7. 打开或刷新 `https://claude.ai/`。已经打开的标签页也要刷新，右下角应出现「桥译」工具条。
8. 可以在浏览器扩展菜单中固定桥译图标，方便打开备用侧边栏。

安装只需加载 `extension/`，不需要安装 Node.js，不需要运行终端命令。

## 模型接口配置

### 打开设置

点击网页右下角工具条的「设置」。也可在普通窗口点击桥译扩展图标 →「模型设置」，或在扩展管理页打开「扩展程序选项」。

### 填写四项基本内容

| 字段 | 填写方法 |
| --- | --- |
| 接口协议 | 选择服务商实际提供的协议；兼容 OpenAI 的网关通常选 Chat Completions |
| API URL | 填 API 地址，不能填聊天网站首页；示例为 `https://api.example.com/v1` |
| 模型名称 | 填服务商提供的准确 model ID，不能用不支持的展示名称替代 |
| API Key | 填拥有该模型调用权限的密钥，不要放进 URL |

支持以下适配方式：

| 协议 | 可填写的地址形式 |
| --- | --- |
| Chat Completions | `/v1` 基础地址或完整 `/v1/chat/completions` |
| Responses | `/v1` 基础地址或完整 `/v1/responses` |
| Anthropic Messages | `/v1` 基础地址或完整 `/v1/messages` |
| Gemini generateContent | `/v1beta` 基础地址或完整模型生成接口 |
| 本机兼容服务 | 例如 `http://127.0.0.1:1234/v1`，高级鉴权可选「无密钥」 |

供应商自定义网关最好填写**完整生成接口地址**。支持 HTTPS；HTTP 仅接受 `localhost` 或 `127.0.0.1`。不是所有任意 URL 都可以调用，私有协议需要增加适配器。

### 测试并保存

1. 点击「测试连接」，根据浏览器提示允许访问你填写的 API 域名。
2. 测试使用**当前表单**，只发送 `Hello.`；成功时看到相应提示。
3. 点击「授权并保存」。**测试成功不会自动保存**，网页功能需要已保存配置。
4. 回到 Claude，等待工具条读取配置；如仍提示未配置，刷新网页。
5. 输入一个简短问题，先手动翻译并检查结果。

默认 Key 只保留到本次浏览器会话结束。勾选「记住密钥」后保存在本机扩展存储，没有额外加密；不要在共用电脑上勾选。修改 API 域名时需要重新填写 Key，不会把旧域名的 Key 自动带给新域名。

### 高级设置

- **术语表**：每行填写一种对应关系，例如 `离焦距离 = defocus distance`，最多 4000 字。
- **鉴权**：通常选择「按协议自动选择」，特殊网关可指定 `api-key` 等方式。
- **Token 上限**：默认 4096；截断时可提高，具体仍取决于模型限制。
- **Token 字段**：Chat 接口不接受 `max_tokens` 时，可按服务商文档改为 `max_completion_tokens` 或不发送。
- **回车译后发送**：可选，默认关闭，见下文。

## 手动翻译提问

1. 在 Claude 原提问框输入中文，并先完成中文输入法选词。
2. 点击提问框旁的「翻译成英文」，或工具条「中文 → 英文」。
3. 等待译文填入提问框，检查英文是否准确。
4. 自己点击 Claude 原发送按钮。

翻译按钮只负责翻译和填入，不自动发送。未发送、未修改的英文草稿可以点击「还原中文」。翻译期间修改草稿时，插件会保留当前内容，避免覆盖新输入。

如果出现「英文已生成，但网页输入框未接受填入」，可在英文预览里点击「复制英文」，再手动粘贴到提问框并发送。备用侧边栏也支持中文草稿 → 英文预览 → 复制或填入。

## 可选回车译后发送

这个功能与「自动译回答」是两个独立开关，**默认关闭**。

### 开启方法

在网页工具条勾选「回车译后发送」即可，选择会保存在本机。也可打开设置 →「高级设置与术语表」→勾选「回车译后发送（可选）」→「授权并保存」。

### 开启后的操作

1. 在 Claude 提问框输入中文，完成选词。
2. 按一次 Enter。
3. 插件先请求英文翻译，确认草稿和会话未改变，再填入英文并检查是否成功。
4. 确认后只点击一次与当前提问框关联的网页发送按钮。

| 输入操作 | 行为 |
| --- | --- |
| 含中文的提问按 Enter | 开关开启时翻译后发送 |
| Shift+Enter | 换行 |
| 中文输入法选词的 Enter | 确认候选，不触发翻译 |
| 纯英文按 Enter | 沿用网页原行为 |
| 点击「中文 → 英文」 | 只翻译，不自动发送 |
| 关闭回车开关 | 不接管新的回车，恢复网页原行为 |

开关关闭时，中文按 Enter 可能由网页直接发送；需要英文提问时请先点翻译按钮。

API 出错、译文仍有汉字、编辑器拒绝填入、草稿被改动、切换会话、取消或关闭开关，都会停止后续自动发送。未识别到可用发送按钮时保留英文供手动发送。连续回车不会重复触发本次操作。

如果提示「尚未确认是否成功」，请先查看会话是否已出现问题，再决定手动处理；插件不会自动重发。已经触发的网页发送不能通过取消翻译撤回。

## 逐段阅读回答

默认开启「自动译回答」。回答生成过程中，已稳定且出现后续内容块的段落会开始翻译，中文紧跟在对应英文段落下面，无需等整条回答结束。

仍在增长的最后一段会等待后续内容块或生成结束。最多两个翻译请求并发；已完成段落会立即显示，后续追加不会重复翻译未改变的前文。

| 显示模式 | 效果 |
| --- | --- |
| 原文 | 显示原英文 |
| 双语 | 英文段落下方紧跟中文，默认模式 |
| 中文 | 在网页原结构中显示中文文字 |

标题、列表、引用、加粗、链接和表格保持原有结构；中文文字沿用对应原文字号，小字号提示保持小字号。

**只翻译文字**：独立代码块、行内代码、公式、图片、SVG、Canvas、图表和视频不交给翻译模型，也不会被重建。双语中的行内代码会从原文在本机原样带入中文段落。附件、Artifact、图片 OCR 和内嵌代码编辑器不在翻译范围内。

旧回答可以点击下方「翻译／重试」。取消或失败时保留已有译文，点击重试仅处理待完成部分，不自动循环重试。刷新网页后临时译文需要重新生成。

## 复制代码和表格

- **独立代码块**：使用 Claude 网页原有的复制按钮，代码保持原样；插件不额外添加代码复制按钮。
- **中文表格**：该表格翻译完成后，点击「复制中文表格」，可粘贴到 Excel 等软件；富表格剪贴板不支持时回退为 TSV。
- **表格 Markdown**：点击该表格的「复制 Markdown」。
- **完整回答**：回答和译文全部完成后，点击「复制中文全文」，得到包含中文文字、原代码及中文表格的 Markdown。

未完成的表格或全文暂不允许作为完整结果复制。图片只在具备已有 HTTP(S) 链接时导出链接，不复制图片位图；公式在可取得原始 TeX 时导出 TeX。

## 无痕模式与 InPrivate

### Chrome

1. 先在**普通窗口**完成安装和模型配置。
2. 普通窗口地址栏打开 `chrome://extensions`。
3. 找到「桥译 · Bridge Translate」，点击「详情」。
4. 打开「允许在无痕模式下使用」（英文界面为 **Allow in Incognito**）。
5. 确认桥译处于启用状态，站点访问允许 `https://claude.ai/`。
6. 按 `Ctrl+Shift+N` 新建无痕窗口；macOS 使用 `⌘+Shift+N`。
7. 在无痕窗口打开 Claude 并登录。无痕窗口与普通窗口的网站登录状态分开，需要重新登录属于正常情况。
8. 刷新 Claude 标签页，确认右下角出现桥译工具条。
9. 先输入一句短中文，点击翻译按钮验证，再按需要开启回车译后发送。

不需要在无痕窗口重新安装。Chrome 不支持在无痕或访客窗口添加扩展，因此安装操作应在普通窗口完成。

### Edge

1. 在普通窗口打开 `edge://extensions`。
2. 找到桥译 →「详情」。
3. 开启「允许在 InPrivate 中使用」（**Allow in InPrivate**）。
4. 用菜单新建 InPrivate 窗口，或在 Windows 按 `Ctrl+Shift+N`。
5. 打开并登录 Claude，刷新页面，确认桥译工具条出现。

Edge 的实际功能兼容性仍需安装后确认。

### 配置与侧边栏

本扩展采用浏览器默认的 spanning 无痕方式，设置不是为每个无痕窗口创建单独的副本；不要把无痕模式理解为密钥会被自动清除。

Chrome 对 spanning 扩展在无痕主标签页打开扩展页面存在限制。因此，**模型设置与 Key 管理优先在普通窗口完成**。若无痕窗口点击设置或侧边栏无响应，切回普通窗口打开桥译选项、保存配置，然后刷新无痕 Claude 页面。网页工具条的逐段翻译是主要使用入口。

默认的会话 Key 可能在整个浏览器会话结束后失效；只关闭一个无痕窗口不应被视为清除 Key 的操作。需要清除时，在设置页点击「删除已保存的密钥」。

### 无痕下仍无法使用

依次检查：无痕权限是否已打开 → 扩展是否启用 → Claude 站点访问是否获准 → 该标签页是否已刷新 → 普通窗口模型设置是否保存 → API 连接测试是否成功。

如果是公司或学校托管浏览器，管理员策略可能限制无痕扩展；不要修改组织策略，向管理员确认。无痕只改变部分本机浏览数据的保存方式，不提供身份隐藏或账号安全保证。

- [Chrome：安装和管理扩展程序](https://support.google.com/chrome/answer/2664769?hl=zh-Hans)
- [Chrome：扩展无痕清单与 spanning 模式](https://developer.chrome.com/docs/extensions/reference/manifest/incognito)
- [Edge：扩展站点访问与 Allow in InPrivate](https://support.microsoft.com/en-us/edge/change-site-access-permissions-for-extensions-in-microsoft-edge)

## 更新与卸载

更新时保持原安装路径，将新包 `extension/` 内文件完整覆盖到原 `extension/`，在扩展管理页点击重新加载，再刷新所有 Claude 标签页。保留原路径有助于延续扩展身份和设置；删除旧扩展后重新安装可能丢失配置。

卸载前可在设置中删除 Key，再到浏览器扩展管理页移除桥译。无需卸载任何服务器组件。

## 常见问题

| 现象 | 处理办法 |
| --- | --- |
| 没有工具条 | 确认网址为 `https://claude.ai/`，启用扩展并允许站点访问，然后刷新 |
| 测试成功但网页仍未配置 | 点击「授权并保存」，仅测试不会保存 |
| 中文没有被替换 | 完成输入法选词；查看错误提示；若填入失败使用英文预览复制粘贴 |
| 翻译后仍有汉字 | 检查名称、引文或代码；插件停止自动填入供人工检查 |
| 401 / 403 | 核对 Key、模型权限与账户状态 |
| 404 | 核对协议、完整接口路径和 model ID |
| 429 | 核对余额与频率限制，稍后手动重试 |
| 400 / 不支持参数 | 按服务商文档调整协议、Token 字段与上限 |
| 网络失败 | 检查域名权限、证书和最终接口地址；插件不跟随重定向 |
| 返回格式错误或缺少编号 | 所选模型需能遵循 JSON 片段翻译要求，可换用更擅长格式遵循的模型 |
| 自动翻译有等待 | 正在增长的末段会等待；模型响应和网络耗时另计，每次请求超时 25 秒 |
| 重启后缺少 Key | 默认会话保存，重新填写，或自行选择记住密钥 |
| 找不到输入框或发送按钮 | 网页可能已改版；刷新，使用预览手动发送，必要时更新适配 |
| 复制全文按钮不可用 | 等待整条回答和所有翻译完成，失败段先重试 |
| 无痕不工作 | 按上一节单独开启无痕权限，并在普通窗口配置模型 |

## 数据流与验证范围

翻译请求从扩展后台发往你指定的 API；该服务商能看到被翻译的文字。插件不会把翻译指令附加到 Claude 问题中，但本产品直接在网页输入、显示中文，没有页面内容隐藏机制。Key 不写入网页，不提供自有服务器或统计上报。

正式版名称代表本次功能定稿，不代表已上架商店。协议与模拟 DOM 回归已通过；真实 Claude、实际模型、原生浏览器编辑器及 Edge 的验收范围详见 [验证记录](验证记录.md)。

## 侧栏对话标题翻译

网页工具条的「对话标题」默认开启。接好 API 后，当前侧栏可见的英文会话标题显示为中文，悬停看英文，关闭立即恢复。沿用原字号、截断和点击行为，不修改云端名称。设置页高级选项也可控制。

只翻译可见会话链接，不扫描全部历史，不翻译项目名或回答中的会话引用。滚动后按需处理新出现的标题，相同标题复用本页缓存，刷新后重建。标题会发送给配置的 API，可能额外计费。提问与回答优先，标题在空闲时批量翻译。失败保留原文，不自动反复重试，关闭再开启可重试。网站改版可能需要更新识别。
