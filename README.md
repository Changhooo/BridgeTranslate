# 桥译 · Bridge Translate

**桥译（Bridge Translate）是专为 Claude 网页制作的中英翻译器。** 支持中文提问转英文、可选回车译后发送、英文回答逐段翻译为中文，以及侧栏对话标题翻译。翻译使用你配置的模型 API。

适用于桌面版 Chrome 116+；Edge 使用同类扩展 API，需在实际浏览器中确认兼容性。无需搭建服务器，也无需编译。

[下载正式版安装包](https://github.com/Changhooo/BridgeTranslate/releases/tag/stable)

## 安装

1. 解压安装包，保留整个文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启右上角「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择包里的 **extension** 文件夹，也就是包含 `manifest.json` 的那一层。
5. 刷新已经打开的 `https://claude.ai/` 网页。右下角出现「桥译」工具条。
6. 点击工具条「设置」，填写 API URL、模型名称和 API Key，可直接点击「测试连接」测试当前表单。连接成功后点击「授权并保存」，供网页翻译使用。首次访问 API 时，浏览器会请求该域名的权限。

也可以点击浏览器扩展图标打开备用侧边栏；在扩展管理页点击「扩展程序选项」也能进入设置。

## 日常使用

- **提问**：直接在 Claude 原提问框输入中文，点击提问框旁出现的「翻译成英文」，或右下角「中文 → 英文」。译文生成后替换提问框，检查后自己点击网页的发送按钮。这两个翻译按钮始终只翻译，不自动发送。
- **可选回车发送**：默认关闭。在网页工具条勾选「回车译后发送」，或者在设置的「高级设置与术语表」中勾选并保存后，中文提问按 Enter 会先翻译为英文，确认填入成功，再点击网页发送按钮。Shift+Enter 仍用于换行；中文输入法选词的回车不会触发翻译；纯英文提问沿用网页原行为。关闭时插件不接管回车，请先手动翻译再发送。设置会保存在浏览器本机。
- **触发方式**：不会边输入边调用翻译。提问通过翻译按钮，或显式开启后的 Enter 触发；「自动译回答」只控制回答。
- **撤销与取消**：手动翻译后，尚未改动或发送的英文可以「还原中文」。翻译期间改稿、切换会话、取消操作或关闭回车开关，都会停止尚未触发的自动发送，保留当前内容。填入后取消时可能已是英文草稿，仍不会自动发送。
- **发送异常**：翻译失败、译文仍含汉字、编辑器拒绝填入，均不自动发送。发送按钮缺失或禁用时保留英文供手动处理。连续回车或翻译中点击发送不会重复提交；点击网页发送后若未观察到清空输入框、开始生成或页面切换，会提示「尚未确认是否成功」，不自动重发。网页状态确认不等同服务器送达回执。
- **回答**：默认开启「自动译回答」，回答生成过程中就处理已稳定且出现后续内容块的段落，将中文紧跟在对应英文段落下方。标题、列表项和表格也按内容块处理，不再在末尾放整条中文卡片。
- **进度**：最多两个翻译请求并发，每段完成后立即显示；前文译文不会因后文追加而清空或重复调用。仍在增长的最后一段先等待，出现后续内容块后即可翻译；回答明确结束后补译最后一段。段落稳定检测约 250 毫秒；无法识别结束标记时，最后一段使用约 1.4 秒稳定等待作为后备。模型与网络耗时另计，网站改版可能需要更新识别。
- **切换**：每条回答下方有「原文／双语／中文」。默认双语；中文模式只替换原页面的普通文字，沿用原来的 Markdown 排版和字号。标题、列表、加粗、引用、链接和表格保留；切回原文可恢复英文。双语模式的中文文字也沿用原节点字号。
- **复制**：移除插件额外添加的「复制代码」，独立代码块使用网页原来的复制功能。`turn()` 等行内代码会原样出现在相邻中文段落中，不再缺字。中文表格完成后可「复制中文表格」粘贴到 Excel 等软件，也可「复制 Markdown」。整条回答及所有译文完成后，「复制中文全文」复制带原代码、中文表格和 Markdown 结构的全文。原文模式下，带「中文」的复制按钮仍复制中文。
- **旧回答**：点击其下方「翻译／重试」按需翻译，已完成且未变动的段落会复用。不会自动翻译整段历史。
- **取消／重试**：工具条可取消当前翻译，保留已有译文并暂停这条回答的新请求。失败时保留失败段原文，点击「翻译／重试」继续；不会自动循环重试扣费。
- **收起**：右下角「收起」缩小工具条，再点击「展开」恢复。

## 无痕模式

先在普通窗口安装。在 `chrome://extensions` 找到「桥译」→「详情」→开启「允许在无痕模式下使用」；然后新建无痕窗口、打开 Claude 并登录、刷新页面。Edge 则在 `edge://extensions` 的详情中开启「允许在 InPrivate 中使用」。完整步骤和无痕设置入口限制见 [使用指南](docs/使用指南.md#无痕模式与-inprivate)。

## 可接入的接口

「任何模型」需要有可兼容的接口协议。当前提供四个适配器，模型名称自由填写，不绑定特定供应商。

| 协议 | API URL 写法 | 默认鉴权 |
| --- | --- | --- |
| OpenAI 兼容 Chat Completions | `https://api.example.com/v1` 或完整 `/v1/chat/completions` | `Authorization: Bearer KEY` |
| OpenAI Responses | `https://api.example.com/v1` 或完整 `/v1/responses` | `Authorization: Bearer KEY` |
| Anthropic Messages | `https://api.anthropic.com/v1` 或完整 `/v1/messages` | `x-api-key` |
| Gemini generateContent | `https://generativelanguage.googleapis.com/v1beta` 或完整模型接口 | `x-goog-api-key` |
| 本机 OpenAI 兼容服务 | 例如 `http://127.0.0.1:1234/v1` | 高级设置中选择「无密钥」 |

DeepSeek 等 OpenAI 兼容服务请选择 Chat Completions；API URL 与 model ID 以服务商当前文档和账号可用模型为准。对于已适配的 DeepSeek 官方地址，插件会规范化 Chat 路径并关闭翻译时的思考模式。

这里的 `example.com` 是示意域名，请替换为自己的服务商地址。支持 HTTPS；仅本机地址允许 HTTP。其他自建网关路径请填写完整生成接口地址。Azure 等服务可填写包含 `api-version` 的完整接口地址，并在高级设置改为 `api-key`。

不要把 Key 放进 URL。Gemini 若填写完整接口，URL 里的模型名优先，请同时保持「模型名称」字段一致。不同模型支持的 Token 参数不同，可在高级设置选择 `max_tokens`、`max_completion_tokens` 或不发送该字段。

如果服务商使用其他私有请求／返回格式，需要增加对应适配器；不是所有任意 HTTP 接口都能直接使用。

## 长文本、代码与术语

单条回答的文字上限为 60000 个字符；普通文字按节点提取，长节点分段，每个段落独立翻译，段内每批约 2600 字符、最多 32 个片段，输出上限默认 4096 tokens。逐段请求的次数可能多于整条合批，最多两个请求并发。每次网络请求超时 25 秒，较慢的推理模型可能不适合即时翻译。

回答已经由网页排版，插件直接沿用现有结构，不把整条回复拆成纯文字后重新生成 Markdown。普通文字以带编号的 JSON 片段发给翻译接口，返回后严格校验编号，再作为文本写入；不执行模型返回的 HTML。接口使用提示词要求 JSON，不依赖服务商专用 JSON 参数；所选模型需要能遵循这一格式。缺漏、重复编号或错误格式会报错并保留原文。

仅翻译普通文字。代码块、行内代码、MathML、KaTeX、MathJax 等公式节点，以及图片、SVG、Canvas、视频等对象不发送给翻译模型，也不替换这些节点。普通文字中常见的 `\(...\)`、`\[...\]`、`$...$`、`$$...$$` 公式和 URL 使用本机占位符保护，译后恢复；占位符损坏会报错。

中文模式保留公式、图片、图表和代码的原始对象与位置。双语译文放在对应段落下方，独立代码块、公式、图片和图表继续在原位置显示，不重新生成。行内代码在中文段落中本机原样复制，不发送给翻译模型。全文复制包含原代码和表格；可取得原始 TeX 的公式会附带 TeX，图片只附带已有 HTTP(S) 图片链接，不复制图片或图表位图。不执行 OCR，也不翻译附件、Artifact 或内嵌代码编辑器。

术语表可填写：

```text
显微镜自动对焦 = microscopy autofocus
离焦距离 = defocus distance
带符号离焦 = signed defocus
```

译文会保持含义，不会主动改写姓名、身份、国籍或所在地。英文结果若仍有汉字，自动替换会停止并显示预览，以便检查中文引文、人名或代码。

## 数据与权限

- 按你的要求，**本版直接在网页输入和显示中文**；没有设计页面内容隐藏机制。
- 翻译请求由插件后台直接发到你配置的 API，翻译提示词不会由插件附加到 Claude 提问中。
- 你选择的翻译服务商能够看到发送给它的原文。如果选用 Anthropic API，翻译内容也会发送给 Anthropic。
- Key 不会写入页面、不存入同步存储，内容脚本无法读取密钥存储。默认只在本次浏览器会话保留；勾选「记住密钥」后存于浏览器本机扩展存储，**没有额外加密**。
- 无自有服务器、广告、遥测或统计上报，不读取 Cookie，不改网络指纹、地域或账户信息。译文和草稿不建立持久历史，刷新页面后重新生成。
- 安装时只请求 Claude 网站访问；翻译 API 的域名权限在保存配置时按需请求。可在浏览器扩展管理中撤销。可在设置页单独删除密钥。
- 任何浏览器插件都不能保证账号不受平台限制。

## 常见问题

**没有工具条**：确认网址为 `https://claude.ai/`，扩展已启用并允许该站点访问，然后刷新网页。手机浏览器和 Firefox 暂不支持。

**点击后仍是中文**：查看右下角具体提示。新版区分「没有识别到输入框」「输入法候选尚未确认」「接口失败」和「英文已生成但网页拒绝填入」。最后一种会保留草稿并打开英文预览，可点击复制。

**找不到提问框／回答**：Claude 可能改动了页面结构。本版使用多个选择器适配，仍可能需要根据新页面更新 `content.js`。侧边栏的手动翻译与复制可以作为备用方式。

**401／403**：检查密钥、账户与模型权限。**404**：检查接口完整路径和模型名称。**429**：检查余额或频率限制，稍后手动重试。**400**：尝试更换 Token 字段，并核对协议。

**连接失败**：确认授予 API 域名权限，使用有效 HTTPS 证书，并填写最终接口地址；为了避免把密钥带到其他目的地，本版不跟随重定向。服务商或浏览器也可能有额外网络限制。

**重启后提示缺少 Key**：默认密钥只在本次会话保留。重新填写，或选择「记住密钥」。

## 文件与开发

- `extension/`：可直接加载的插件源码，无运行时第三方依赖。
- `docs/产品设计.md`：交互规则与产品边界。
- `docs/验证记录.md`：本次实际验证范围及限制。
- `tests/core.test.mjs`：协议、长文本与保护逻辑测试。
- `tests/dom.test.mjs`：模拟网页与 Chrome API 的交互逻辑联调。
- `tests/browser.test.mjs`：可在本机运行的真实 Chromium 扩展与本地模型模拟联调脚本。
- `tests/claude-fixture.html`：仅用于测试的模拟页面，不连接 Claude。
- `extension/dom-text.mjs`：文字节点映射、行内代码本机保留与原字号保留。
- `extension/paragraphs.mjs`：段落识别、稳定判断、译文定位、修订失效及分段状态。
- `extension/clipboard.mjs`：代码、富表格、TSV 与 Markdown 全文导出。

开发验证：安装 Node.js 20+，在项目目录运行 `npm install` 和 `npm test`。真实浏览器验证另运行 `npx playwright install chromium`、`npm run test:browser`。浏览器测试在临时副本中额外授权本机模拟 API，发布目录不带该额外权限，不使用真实账户或付费模型。

本项目以当前功能作为正式版交付，通过「加载已解压的扩展程序」安装，尚未上架扩展商店；真实 Claude 页面与实际 API Key 需要安装后验收。

## 侧栏对话标题翻译

网页右下角的「对话标题」开关默认开启，接好翻译 API 后，左侧「最近使用」中当前可见的英文会话标题会显示为中文。悬停查看英文原名；关闭开关立即恢复原文。标题沿用网站字号、截断和点击行为，**不修改云端会话名称**。设置页的「高级设置与术语表」也可控制。

只读取当前侧栏已显示且在可见区域的会话链接，不扫描全部历史，不翻译项目名或回答中的会话引用。滚动列表后按需翻译新出现的标题；相同标题复用本页内存缓存，刷新后重建。标题作为额外文字发送给你配置的翻译 API，可能产生费用。提问与回答优先，标题在空闲时批量处理；失败保留原文，不自动反复重试，可关闭再开启开关重试。Claude 页面结构变化可能需要更新识别。
