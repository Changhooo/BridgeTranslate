# 桥译 · Windows CC 桌面版

本包专用于 **Claude Desktop 中的 Claude Code（Code 会话）**，以官方 Mods 插件运行。无需 Chrome 扩展，不修改 Claude 安装文件，不注入普通 Chat 界面。浏览器版位于项目 `extension/`，两者可分别安装。

当前提供可安装源码与 Windows 安装脚本。已通过模拟 Mods API 回归；**尚未在真实 Windows CC 桌面端安装验收，也未运行官方 `claude plugin validate`**。这份说明不把模拟测试当作实机通过结果。

## 安装前确认

1. 打开 Windows 的 Claude 桌面应用，进入 Code，打开一个**本机会话**。
2. 输入 `/status`，查看 Claude Code 的版本。官方 Mods 从桌面内置引擎 `2.1.286` 起可用；本包建议更新至 **2.1.299 或更新版本**。
3. 普通 Chat、Cowork、浏览器插件页不是这个安装目标；首次验收也先不用 SSH、云会话或 WSL 会话。
4. 备好翻译服务商提供的 API URL、model ID 和 Key。

这里的版本指 `/status` 中的 Claude Code 引擎版本，不是 Windows 应用列表里显示的桌面壳版本。若 `/status` 或 Mods 功能不可用，请先更新官方应用，不要通过绕过组织策略启用插件。

## Windows 安装

1. 将 `BridgeTranslateCC.zip` 完整解压到固定目录，例如 `D:\Apps\BridgeTranslateCC`。
2. 完全退出 Claude，包括系统托盘里的后台进程。
3. 双击「安装桌面版.cmd」。不需要管理员权限。
4. 脚本会读取用户的 `.claude/settings.json`，在写入前备份，然后把本插件的绝对路径追加到 `env.CLAUDE_CODE_PLUGIN_DIRS`。已有设置与其他插件路径保留。无效 JSON 会报错并停止。
5. 重新启动 Claude，打开本机 Code 会话，输入 `/plugin`，检查桥译是否加载及 Errors 页是否报错。
6. 输入 `/bridge` 打开桥译控制面板。支持对应渲染入口的版本也会在原提问框上方显示工具条。

插件从解压目录直接读取，安装后不要移动或删除该目录。CMD 只为本次运行的 PowerShell 进程设置执行方式，不修改系统的永久执行策略。

### 手动登记路径

不想运行脚本时，退出 Claude，备份并编辑 `%USERPROFILE%\.claude\settings.json`，把本插件路径合并进现有 `env`：

```json
{
  "env": {
    "CLAUDE_CODE_PLUGIN_DIRS": "D:\\Apps\\BridgeTranslateCC\\bridge-translate-cc"
  }
}
```

上面只展示相关字段，**不要用它覆盖已有完整文件**。多个插件路径以英文分号 `;` 分隔。若自行设置了 `CLAUDE_CONFIG_DIR`，应编辑该配置目录中的 `settings.json`。

## 配置翻译模型

在 `/plugin` 中找到桥译并打开 Configure；本地路径加载时，也可尝试输入：

```text
/plugin configure bridge-translate-cc@inline
```

如果当前版本不提供该入口，可用官方 CLI 配置命令，或先检查 `/plugin` Errors 是否拒绝了插件。保存后插件会重新加载，再运行 `/bridge`。

| 字段 | 如何填写 |
| --- | --- |
| 接口协议 | `chat`、`responses`、`anthropic`、`gemini` 之一 |
| 翻译 API URL | 自己的 API 地址，如 `https://api.example.com/v1`；不是聊天网页地址 |
| 翻译模型 ID | 服务商实际提供的 model ID |
| 翻译 API Key | 调用翻译服务所需的 Key |
| 鉴权方式 | 通常选 `auto`；本机无密钥服务选 `none` |
| 输出 Token 上限 | 默认 4096，超长内容可按模型限制调整 |
| 术语表 | 可选，每行写 `中文 = English` |

`api.example.com` 是示例，不能直接使用。四类协议复用浏览器版的纯协议适配器；支持 HTTPS，自建本机服务可以使用 `http://127.0.0.1:端口/v1`。

Key 声明为官方插件的 `sensitive` 配置字段，由支持该功能的 CC 版本存入系统安全凭据存储；本插件不把 Key 写进 `.claude/settings.json`、回答或提问中。桌面版的网络请求由 CC 宿主发出，超时和重定向受宿主管理，与浏览器版的网络策略不完全相同。

配置后在 `/bridge` 面板点击「测试连接」。成功后再使用真实问题。测试仅发送 `Hello.`，不使用本项目服务器。

## 中文提问：手动模式

1. 在 CC **原提问框**输入中文，完成输入法选词。
2. 点击「中文 → 英文」。
3. 译文填入原提问框，检查后自己发送。
4. 需要恢复时，在 `/bridge` 面板点击「还原中文草稿」。草稿已经改变时不会覆盖。

翻译按钮本身不发送。翻译期间改稿、切换会话或取消时，会停止待写入的译文。当前宿主拒绝填入时会给出提示，不把仅生成英文视为填入成功。

## 可选自动译后提交

**默认关闭**。在桥译工具条或控制面板点击「自动译后提交：关」，切换为「开」，选择保存在本机。

开启后，在原提问框提交中文问题，会执行：中文 → 独立翻译 API → 校验英文 → 交给 CC 原提交流程。插件通过 `prompt.submit` 替换本次提问，不把「请翻译」等指令追加给 Claude。

桌面官方接口捕获的是**提交动作**，因此它同时覆盖 Enter 和发送按钮，不能在此接口中可靠地区分两者。按钮名称据此使用「自动译后提交」。换行和中文输入法按原应用处理，插件不接管系统键盘事件。

关闭后插件不拦截中文提交，原应用可能直接发送中文；如需要英文提问，请先手动翻译。

翻译失败、仍有汉字、重复操作、取消、关闭开关或会话结束时，自动流程返回停止结果，不主动转交原中文。宿主超时的错误处理也设为停止提交；这仍需要在你的实际 CC 版本中验收。已经通过原提交流程的请求不能靠取消翻译撤回。

## 自动翻译回答

默认开启「自动译回答」。在新回答生成时，插件按 Markdown 内容块处理已闭合的段落，中文显示在对应英文段落下；仍在增长的末段等待回答结束再补译。最多两个翻译请求并发，未改变的已完成段落复用。

「显示」按钮依次切换双语 → 中文 → 原文。插件修改 `AssistantMessage` 的**显示文本**，仍由 CC 原生 Markdown 渲染器排版。标题、列表、表格等沿用原生 Markdown 支持；字号和代码复制控件的实际表现以宿主为准，需要实机验收。

- 代码块、行内代码、公式和 Markdown 图片内容以本机保护处理，不把内容交给翻译 API。
- 工具调用卡片、Diff 编辑器、附件与图片像素不翻译。
- 不做 OCR，不重建图片，也不调用 Claude 来生成中文。
- 插件只缓存本会话最多 20 条已渲染文本块，超过 60000 字的单块保留原文。
- 段落翻译出错会保留英文，不自动反复请求；点击「翻译／重试」处理当前记录。
- 取消会暂停自动翻译并丢弃未完成结果；已经发出的宿主 HTTP 请求可能仍继续并计费。

自动翻译以会话正在生成、且宿主实际渲染的回答为入口；不是后台批量翻译全部历史。滚动时实际选择的回答以最近渲染记录为准。

## 复制代码与表格

代码块继续使用 CC 原生 Markdown 渲染器提供的复制功能。

整条记录和译文完成后，点击「复制中文 Markdown」，得到中文正文、原代码、原公式与表格 Markdown。该按钮依赖当前 CC 提供的 `$.ui.copy`；较旧宿主缺少时会提示切换中文并使用原生选中复制。

桌面版当前提供 Markdown 复制，不包含浏览器版的富表格／TSV 剪贴板功能；图片保持 Markdown 链接，不复制图片位图。

## 数据流与边界

被翻译的文字发送到你选择的 API，该服务商可以看到原文。插件不注册模型可见的翻译 Skill 或 MCP 工具，不追加翻译指令，不把中文回答写回会话记录或模型上下文。

这说明的是**本插件的模型数据路径**，不等于对 Claude 桌面程序本身、其他插件、操作系统或服务端日志作出不可见保证。插件运行在 Claude Code 宿主中，不能保证账号不受平台限制。

## 排错

| 问题 | 处理 |
| --- | --- |
| 找不到桥译 | 检查是 Code 本机会话，完全重启应用，检查 `/status` 与 `/plugin` Errors |
| 只在 CLI 出现 | 桌面内置引擎与 CLI 不一定同版；在桌面自己的 `/status` 检查 |
| 组织阻止 Mods | 向管理员确认；本安装器不修改组织策略 |
| 配置后没变化 | 重新加载插件或重启本机会话，再运行 `/bridge` |
| 自动提交没有启用 | 这是默认行为，需要在桥译面板主动开启 |
| 原稿没被覆盖 | 检查是否翻译期间改稿或会话变化，确认当前没有其他提问任务 |
| 401/403 | 检查 Key、账户、模型权限 |
| 404 | 检查完整 API 路径、协议与 model ID |
| 429 | 检查余额与频率，稍后手动重试 |
| 末段还没中文 | 等回答结束；网络和模型耗时另计 |
| 复制失败 | 当前宿主可能不支持插件剪贴板，更新应用或使用原生复制 |

## 卸载

1. 在官方插件配置中清除不再需要的 API Key。
2. 完全退出 Claude。
3. 双击「卸载桌面版.cmd」，只从插件目录列表中移除本路径，保留其他设置。
4. 重启 Claude。安装脚本的配置备份保留在原配置目录。
