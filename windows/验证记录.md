# Windows 独立版验证记录

本记录对应不依赖 Mods 的独立程序。

## 已实际完成

- 使用官方 .NET 8 SDK 8.0.426 交叉编译 WPF 应用为 Windows x64 自包含 GUI EXE。
- `file` 检查确认为 PE32+ GUI x86-64 Windows 可执行文件。
- 核心控制台检查 **37 项通过**：四种协议 URL、拒绝非本机 HTTP 与 URL 内密钥、代码／公式／图片与链接本机保护、占位符校验、Markdown 分段、未闭合代码保护、扩展汉字检测、只提取助手 text、跳过用户及思考／工具内容、修订失效、Markdown 安全排版、TeX 恢复、图片延迟加载、错误正文隔离、翻译后汉字检查、JSONL 不完整 UTF-8 缓冲及不重复读取。
- 阅读区模拟 DOM 检查 **4 项通过**：移除脚本与危险链接、远程图片按点击加载、代码／表格复制、HTTPS 链接转交、KaTeX 非信任渲染。
- 阅读区 JavaScript 语法、项目 XML、安装包完整性与资源路径检查。
- KaTeX 从 npm 官方分发包下载并验证包的 SHA-512 integrity；许可证随包。

## 尚未完成

1. 当前环境是 Linux，**没有启动 Windows GUI，也没有真实 Windows 界面截图或桌面实录**。
2. 未在用户的 CC 版本中验证窗口／输入框／发送按钮绑定、可访问文字、ValuePattern、焦点验证与粘贴回退。
3. 未在 Windows 验证中文输入法回车行为、系统剪贴板、DPAPI 和 WebView2 Runtime 的实际初始化。
4. 没有使用真实 API Key 或付费模型，供应商网络与参数兼容需通过程序内测试确认。
5. JSONL 解析覆盖的是常见助手 text 记录；CC 桌面版实际保存路径、格式与写盘频率需要实机确认。读取文件不等于收到实时 token 流。
6. 自动发送无法取得 CC 内部权威会话 ID；窗口标题和控件未变化的内部会话切换可能无法检测。使用时应保持目标会话不变，首次使用先验收“填入 CC”。
